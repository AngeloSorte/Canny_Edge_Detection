# Canny Edge Detection with OpenCV

This simple computer vision project demonstrates how to perform Canny Edge Detection using OpenCV and NumPy in a Google Colab notebook.

## 📌 Description

The notebook allows you to:
- Upload an image from your local system.
- Convert the image to grayscale.
- Apply Gaussian blur to reduce noise.
- Detect edges using the Canny algorithm.
- Display the original and processed images.

## 🛠️ Dependencies

- opencv-python
- numpy

Install them via:
pip install -r requirements.txt



## 🚀 Run the notebook

Open the `Canny_Edge_Detection.ipynb` file in [Google Colab](https://colab.research.google.com/), run the cells, and upload your image to see the edge detection result.
